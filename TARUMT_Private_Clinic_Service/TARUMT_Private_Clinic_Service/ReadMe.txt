// Explanation of how to run our system
// TITLE: TARUMT Private Clinic Services System


// =================================================
//                     PATIENT
// =================================================

1. when you run the code, you will see the main menu interface.
2. enter [1] to enter the patient module.
3. if you have register an account just type your patient ID then can login. If you are new patient, then can register a new patient account.
4. when you successfully login, then will enter the patient module menu.

// FUNCTION (enter the number to visit the page)

// [1] UPDATE PROFILE
if you consider to change your name/phone number/etc, you can enter [1] to visit this function to perform the changing action.

// [2] VIEW MY PROFILE
here to view your full profile information, example name, phone number, etc.

// [3] BOOK APPOINTMENT / CONSULTATION
you can start to choose the doctor profession and choose the specific doctor, and describe your symptom.

// [4] CANCEL APPOINTMENT
if you have emergency or feel better, can cancel your appointment, but need to give valid reason and wait for admin to approve.

// [5] VIEW APPOINTMENT HISTORY
here can show your all appointment record.

// [0] LOGOUT
exit your account and back to main menu.



// =================================================
//                     DOCTOR
// =================================================

1. when you run the code, you will see the main menu interface.
2. enter [2] to enter the doctor module.
3. if you have register an account just type your doctor ID then can login. If you are new doctor, then can register a new doctor account.
4. when you successfully login, then will enter the doctor module menu.

// FUNCTION (enter the number to visit the page)

// [1] VIEW AND MANAGE APPOINTMENTS
here you can view the appointment, see what patient book your consultation. When you finish consult with your patient, then can edit their status, if the patient need medicine you can change their status into 'TO-COLLECT MEDICINE', if not then can change to 'COMPLETE'.

*NOTE: if the patient didn't come to the appointment, then you can change their status to 'CANCEL' with a valid reason and wait the admin to approve.

// [2] VIEW PERFORMANCE REPORTS
here you can see your total appointment history, you also can filter your reports.

// [3] UPDATE PERSONAL PROFILE
if you consider to change your information can visit this page.



// =================================================
//                     ADMIN
// =================================================

1. when you run the code, you will see the main menu interface.
2. enter [3] to enter the admin module.
3. enter admin ID that already initial to login. When you successfully login, then will enter the admin module menu.


// FUNCTION (enter the number to visit the page)

// [1] MANAGE PATIENT ACCOUNT
here you can see all patient account who have been visit in the TARUMT private clinic. You can add new patient if the patient face some registration problem. 

you also can update the patient profile if need. If some patient violating the rule or they want to quit the clinic, you can remove their account.

// [2] MANAGE DOCTOR ACCOUNT
here you can see all doctor account who have been work in the TARUMT private clinic. You can add new doctor if the doctor face some registration problem. 

you also can update the doctor profile if need. If some doctor violating the rule or they want to quit the clinic, you can remove their account.

// [3] MANAGE APPOINTMENT
here you can approve or reject the appointment that have been cancelled by patient or doctor with a valid reason. If approve the appointment status will change to 'CANCEL' if reject then will change to 'PENDING'

// [4] VIEW REPORT & SUMMARY
here you can show the clinic visit report, clinic summary report and doctor performance.

// [5] MANAGE PHARMACIST ACCOUNT 
here you can see all pharmacist account who have been work in the TARUMT private clinic. You can add new pharmacist if the pharmacist face some registration problem. 

you also can update the pharmacist profile if need. If some pharmacist violating the rule or they want to quit the clinic, you can remove their account.



// =================================================
//                     PHARMACY
// =================================================

1. when you run the code, you will see the main menu interface.
2. enter [4] to enter the pharmacy module.
3. if you have register an account just type your pharmacist ID then can login. If you are new pharmacist, then can register a new pharmacist account.
4. when you successfully login, then will enter the pharmacy module menu.

// FUNCTION (enter the number to visit the page)

// [1] MEDICINE MANAGEMENT
here you can see the all medicine, and also you can add the new medicine or update the medicine details.

if the medicine is out of stock then you can remove the medicine.

you also can search the medicine by using name, ID or category.

// [2] DISPENSE MEDICINE
when the doctor change the patient status into 'TO-COLLECT MEDICINE', before dispense medicine will show for you the patient list who need to collect the medicine. Then you can give the medicine based on the doctor feedback remarks.

// [3] REPORTS & DISPLAY
you can see the medicine stock summary and low stock alert report. If you feel the medicine quantity is something wrong you can see the prescription history which display the dispense medicine record.

If you consider to think which medicine used the most you also can view the report.

// [4] EXPORT DATA
if you need to export the report, you can export it into txt file to be use in the future.


// SYSTEM EXPLANATION END
